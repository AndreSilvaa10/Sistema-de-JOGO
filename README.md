# 🎮 Sistema de Jogo

Projeto desenvolvido em **Kotlin** com o objetivo de praticar conceitos fundamentais de programação por meio da criação de um sistema simples de jogador.

O projeto faz parte do meu processo de aprendizado em **Desenvolvimento de Sistemas**. 🚀

---

## 📖 Sobre o projeto

O **Sistema de Jogo** simula algumas ações básicas de um jogador, utilizando informações como:

* 👤 Nome do jogador
* 🎂 Idade
* ❤️ Vida
* ⭐ Pontuação
* 💰 Dinheiro
* 🎮 Status do jogador

O usuário pode interagir com o sistema através de um **menu no terminal**, escolhendo diferentes ações.

## ▶️ Como executar

Para executar o projeto, é necessário ter o **Kotlin/JDK** configurado no computador.

Clone o repositório:

```bash
git clone https://github.com/AndreSilvaa10/Sistema-de-JOGO.git
```

Entre na pasta:

```bash
cd Sistema-de-JOGO
```

Depois, compile e execute o arquivo principal utilizando Kotlin.


## Como Ativar o Venv.

Coloca assim no terminal: venv\Scripts\activate
Obs: tem que ter o python instalado
